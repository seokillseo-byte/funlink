## Included screens

Customer workspace:
- Overview
- Links
- Custom domains and DNS/SSL status
- Campaigns
- QR codes
- Analytics
- Click history
- API keys and webhooks
- Plans and invoices
- Workspace settings

Access and administration:
- Login and registration screen
- Admin dashboard overview
- Admin navigation entry points for users, workspaces, billing, system health, and audit logs

## Preview behavior

- Sidebar navigation switches between complete page layouts.
- Login/register tabs switch form states.
- Create actions open contextual forms.
- Filters, export, save, and other controls show demo feedback.
- All metrics and records are illustrative; no API, authentication, billing, or production data is connected.

## Scope and safety

Static frontend preview only. This branch does not replace the production application, alter the VPS, touch DNS, or connect to the production database. The approved dashboard visual language is retained and extended.
